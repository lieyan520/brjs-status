接入 Supabase 免费数据库（3 步）

  1. 打开 supabase.com 注册并新建项目（免费版即可）。
  2. 左侧 SQL Editor → 新建查询 → 粘贴下面的建表语句并点 Run。
  3. 左侧 Project Settings → API 复制 Project URL 与 anon public key，填到下面的输入框（或写进仓库的 js/config.js，这样所有访客都能连上）。
再在 Authentication → Users 里新建一个管理员邮箱密码，并用它登录即可编辑。

注意：anon public key 是公开密钥，可以安全地放进网页；真正的写入权限由登录账号 + 数据库策略控制。 为了让 所有访客 都能看到服务器列表，请把这两个值写进 js/config.js 后提交到 GitHub。
